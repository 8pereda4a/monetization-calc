📖 Как разместить

Пошаговая инструкция GitHub Pages + Telegram

Шаг 1 — GitHub Pages (бесплатный хостинг)
1. Зайди на github.com → зарегистрируйся
2. Нажми New repository
3. Назови: monetization-calc
4. Поставь галочку Public
5. Загрузи файл monetization-tg.html
6. Переименуй его в index.html
7. Зайди в Settings → Pages → Branch: main → Save
8. Через 2 мин твой URL: username.github.io/monetization-calc
Шаг 2 — Создать Telegram Bot
1. Открой Telegram → найди @BotFather
2. Напиши /newbot
3. Введи название: 8 Передача Монетизация
4. Введи username: pereda4a_calc_bot
5. Скопируй токен — он понадобится
6. Напиши /newapp → выбери своего бота
7. Вставь URL из GitHub Pages
8. Готово — бот создан!
Шаг 3 — Настроить кнопку в боте
В @BotFather напиши:
/setmenubutton
→ выбери бота → введи URL приложения

Теперь в чате с ботом появится кнопка «Открыть» — нажав её, откроется калькулятор прямо внутри Telegram.
Шаг 4 — Поделиться с автором
Отправь автору канала ссылку:
t.me/pereda4a_calc_bot

Он открывает бот → нажимает кнопку → видит калькулятор с журналом учёта. Каждый месяц заполняет данные — ты видишь ту же статистику.
Время на настройку
GitHub Pages: ~10 минут
Telegram Bot: ~5 минут
Итого: ~15 минут
Стоимость: бесплатно
